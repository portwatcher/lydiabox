# Interface review skills

These repository-local skills come from
[jakubkrehel/skills](https://github.com/jakubkrehel/skills) at commit
`72bdd6121cd595f47fd21c9f23e374028c9cbacd`. The upstream files are unchanged;
their MIT license is preserved in [LICENSE](LICENSE).

Use `$better-interface` to review a screen, flow, or interface. Its six domain
skills are included so the review works without a global skill installation:
`better-accessibility`, `better-layout`, `better-writing`, `better-typography`,
`better-colors`, and `better-ui`.

Agents discover these skills from `.agents/skills`; they are available on the
next turn after installation. A review is read-only unless implementation is
also requested.
